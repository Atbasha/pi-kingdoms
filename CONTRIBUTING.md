# Contributing to Pi Kingdoms

Thank you for your interest in contributing! This document provides guidelines for contributing to the Pi Kingdoms project.

## Code of Conduct

Be respectful, inclusive, and constructive. Treat all community members with courtesy.

## Getting Started

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/YOUR_USERNAME/pi-kingdoms.git`
3. **Create a branch**: `git checkout -b feature/your-feature-name`
4. **Setup** development environment (see README.md)
5. **Make** your changes
6. **Test** thoroughly
7. **Commit** with clear messages
8. **Push** to your fork
9. **Create a Pull Request**

## Development Guidelines

### Code Style

- Use TypeScript for type safety
- Follow ESLint configuration
- Format code with Prettier
- Write meaningful variable/function names
- Add comments for complex logic

### Git Commits

Use conventional commits:

```
feat: Add new feature
fix: Fix bug
docs: Update documentation
refactor: Refactor code
test: Add tests
chore: Maintenance
```

### Testing

- Write tests for new features
- Ensure all tests pass before PR
- Aim for >80% code coverage
- Run: `npm test`

### Documentation

- Update README.md for user-facing changes
- Add JSDoc comments to functions
- Update API documentation for endpoint changes
- Include examples for complex features

## Pull Request Process

1. Update documentation
2. Add/update tests
3. Ensure CI passes
4. Request review from maintainers
5. Address feedback
6. Merge when approved

## Reporting Issues

When reporting bugs:

1. Search existing issues first
2. Use a clear, descriptive title
3. Provide steps to reproduce
4. Include expected vs actual behavior
5. Add screenshots/logs if relevant
6. Specify environment (OS, Node version, etc.)

## Feature Requests

When suggesting features:

1. Use a clear title
2. Describe the motivation
3. Explain the expected behavior
4. Provide examples or use cases
5. Consider Pi Network compliance

## Questions?

Open a GitHub Discussion or email support@pikingdoms.dev

Thank you for contributing! 🎮
